# Portfolio computational architecture

The repositories form a governed computational portfolio rather than a monolith:

- **PRIME** — private cognitive control plane, memory, model routing, compute ledger and event coordination.
- **The Portal** — public semantic knowledge/discovery and experiment graph.
- **VELYQUA** — physical-world observation and freshwater digital-twin experiment.
- **Game Platform** — independent commercial RPG plus bounded simulation primitives.
- **Authority Engine** — public evidence/PROVE layer.

Cross-product exchange uses Portfolio Event v1 with evidence level and provenance. Integration never changes the independence, secrets, databases or deployment authority of a product, and no event grants external actuation authority.
